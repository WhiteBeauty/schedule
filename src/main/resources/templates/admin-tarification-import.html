📊 Импорт тарификации

Загрузите файл тарификации (Excel, лист "Часовка") — годовую сводную таблицу часов по преподавателям, дисциплинам и группам с разбивкой на семестры. Преподаватели и дисциплины сопоставляются с уже существующими в базе по ФИО/названию, а учебные группы создаются заново из файла. После импорта используйте обычное автосоставление расписания — оно рассчитает часы в неделю от плановых часов и расставит пары по дням.
